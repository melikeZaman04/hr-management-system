Admin / HR

İşverenin hızlıca anlayacağı güçlü taraflar.

Bu vitrin projenin sadece ekran tasarımı olmadığını gösterir: rol bazlı erişim, gerçek servis katmanı, Supabase Auth, PostgreSQL, Storage ve RLS düşünülmüş durumda.

Gerçek iş akışları

Çalışan oluşturma, izin onayı, cihaz atama, doküman yükleme ve CSV dışa aktarma gibi uçtan uca süreçler.

Rol bazlı ürün mantığı

Admin/HR, manager ve employee profilleri için farklı veri görünürlüğü ve güvenli erişim modeli.

Teslim edilebilir yapı

README, akademik raporlar, Supabase kontrol scriptleri ve production build komutları ile tamamlanmış proje düzeni.

Modül gezgini.

Aşağıdaki sekmeler işverene projenin kapsamını birkaç saniyede anlatmak için hazırlandı.

    
      
    
    
    

    
    
      
    
        
    Mimari akış.
    
        
    Frontend tarafı servis katmanı üzerinden Supabase API ile konuşur. Yetki kontrolünün ana zemini Supabase RLS kurallarıdır.
    
      
    
      
    
        
    01React Sayfası
    Route bazlı ekranlar kullanıcı işlemine göre servis çağırır.
    
        
    02Feature Service
    Çalışan, izin, cihaz, doküman ve maaş iş mantığı ayrılır.
    
        
    03Supabase Client
    Auth oturumu ve API erişimi merkezi client ile yönetilir.
    
        
    04PostgreSQL / Storage
    Veriler tabloda, çalışan dosyaları private storage alanında tutulur.
    
        
    05RLS Güvenliği
    Frontend guard deneyimi iyileştirir; gerçek yetki kontrolü backend tarafındadır.
